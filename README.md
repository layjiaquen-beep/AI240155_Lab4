## Project Description
This project contains three JavaScript exercises completed for Lab 4a. The exercises demonstrate basic JavaScript programming and DOM manipulation.

## Questions

### Question 1: Change Text
A button is used to change the text displayed on the webpage to "Hello there!" when clicked.

### Question 2: Smart Number Validator
The user enters a value and clicks a button to check whether the number is less than, equal to, or greater than 10. The program also handles invalid or empty input.

### Question 3: Dynamic Number Generator
A button generates a list of numbers from 1 to 5 using a JavaScript `for` loop and DOM manipulation.
